### To run the notebook, please run the "py3SEB-UAV.ipynb" jupyter notebook file in the repository ###

- If you have Git installed on your computer, you can clone this repository using:

    ***git clone https://github.com/crop-sensing/py3SEB-UAV.git***

- Alternatively, you can download the shared folder directly from GitHub without cloning it, but you will not see any updates after you download it until you re-download the folder

- Then, navigate to the shared folder in your terminal

    ***(e.g. cd /path/to/py3seb-uav)***

- To create the py3seb-uav environment, type in the following command using conda:
  
   ***conda env create -f environment.yml***
